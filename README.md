# Teste Prático de Programação Java

Resolução do teste prático de programação Java descrito em `Teste.txt`: um cadastro de funcionários com as classes `Pessoa`, `Funcionario` e `Principal`.
Projeto em Java puro, sem build tool.

## Pré-requisito

- JDK 17 ou superior instalado.

## Como compilar e rodar

Java puro, compilado e executado diretamente com o JDK:

```bash
javac *.java
java Principal
```

## Saída

A execução de `Principal` imprime no console, em ordem, o resultado dos itens 3.1 a 3.12 do enunciado (`Teste.txt`).
